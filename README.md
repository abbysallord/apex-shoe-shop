# APEX Footwear | Engineered for Velocity

An ultra-premium e-commerce landing page and 3D interactive shoe customizer built with Tailwind CSS, GSAP animations, and interactive vanilla JavaScript.

## 🚀 Live Preview
• https://apex-shoe-shop.pages.dev

## 📦 GitHub Repository
• https://github.com/abbysallord/apex-shoe-shop

## ✨ Features
• **Immersive Hero:** High-impact typography and animated flagship product showcase.
• **Interactive Color Customizer:** Switch between colorways in real-time with smooth GSAP transitions.
• **Dynamic Slide-over Cart:** Fully reactive shopping cart with live subtotal calculation and quantity adjustments.
• **Curated Collection & Filters:** Instant category filtering for running and lifestyle editions.
• **Athlete Testimonials & Tech Breakdown:** Detailed insights into carbon fiber propulsion and nitrogen-infused cushioning.
